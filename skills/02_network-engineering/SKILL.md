# Network Engineering
Identify source/destination, protocol, port, direction and time window. Use verified MCP tools for DNS, IP/CIDR, ASN/provider, routing and firewall state. Correlate network evidence with service metrics and logs. Distinguish observed traffic from configured policy. No firewall or routing changes without approval.
