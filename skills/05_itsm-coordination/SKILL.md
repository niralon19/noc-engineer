# ITSM & Coordination
Consume Jira webhook events and reconcile with bounded polling. Search for an existing issue before creating one. Preserve correlation IDs and idempotency. Never invent project keys, priorities, assignees, transitions or SLA values. Mutations require workflow authorization and approval policy.
